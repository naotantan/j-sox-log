# J-SOX・監査ログ管理の資料集

システムログの管理と監査ログの保存期間について、ガイドラインをまとめたリポジトリです。収録しているのは、次の2種類の資料です。

- J-SOX に対応したシステムログ管理のガイドライン（開発ベンダー向けの要求事項。本編）
- 本編を基に、業種ごとの法令を反映した業種編（自動車と、日本の主要10業種の全11冊）

業種編の付録に収録した法令調査は、いずれも法的助言ではありません。保存期間の最終的な決定には、法務部門と監査部門（内部統制）の確認が必要です。

## 収録ファイル

PDF は、すべて `資料/` フォルダに入っています。

### 1. `資料/J-SOX_システムログ管理ガイドライン_AWS環境版_本編_v1.2.pdf`

金融商品取引法に基づく内部統制報告制度（J-SOX）に対応するための、システムログ管理の要求事項をまとめた本編です（全317ページ）。財務報告に関連するシステムを AWS 上に構築・運用するときに、開発ベンダーが設計・実装・引継ぎする事項を、内部統制の要件と AWS のサービスに対応付けています。企業名などの固有の情報は含みません。

主な構成は次のとおりです。

- 0章 はじめに: 目的、対象読者、適用範囲、責任分担
- 1章 J-SOXとIT統制の基礎: ログが必要な理由を、IT統制の三層、ITGC、監査人の視点から説明
- 2章 ログ管理要求事項（LR-01〜LR-14）: 対象範囲、記録項目（5W1H）、時刻同期、改ざん防止、保存期間、アクセス制御、暗号化、監視、定期レビュー、変更管理など14項目の要求事項
- 3章 ログ種別と取得対象マトリクス（L-01〜L-14）: 取得するログ種別の一覧と、対象システムへの当てはめ
- 4〜5章 AWSサービス対応詳細: CloudTrail、Config、CloudWatch Logs、S3、KMS、IAM、Systems Manager、RDS/Aurora/DynamoDB（Amazon RDS for Db2 を含む）、ネットワーク/エッジのログ、セキュリティ検知、通知・自動化、分析・抽出、Backup、CI/CD、Organizations、Artifact など、要求事項に対応する AWS のサービス
- 6章 リファレンスアーキテクチャ: マルチアカウント/単一アカウントの構成、ログの流れ、ログアーカイブアカウントの設計、監査人のアクセスの設計
- 7章 保存期間とライフサイクル設計: 参照する法令・基準、推奨する保存期間、階層化の実装、削除の手続
- 8章 改ざん防止と完全性の実装: 脅威モデル、CloudTrail のログファイルの整合性検証、S3 Object Lock による WORM 化、完全性のテスト
- 9章 監視・アラートと定期レビュー運用: アラートの一覧、レビューの一覧、例外・逸脱の扱い
- 10章 職務分掌とログへのアクセス制御: 役割と権限のマトリクス、特権IDの管理、アクセス権の棚卸
- 11章 開発ベンダーの実装責任と成果物: フェーズ別の実施事項、成果物の一覧、テストの観点、受入のチェックリスト
- 12章 監査対応: 証跡の抽出手順と、監査人への提出方法
- 13章 導入ロードマップと移行時の留意点: 段階的な導入、オンプレミスや既存の AWS 環境からの移行、発注者との合意事項のチェックリスト
- 付録: 用語集、参考文献

各冊の構成は、Ver.1.2 と同じ 0〜13 章と付録です。Ver.1.2 から変えた点は次のとおりです。

- 保存期間の推奨（2.5 節 LR-05、第7章）を、根拠とした調査のログの3区分に合わせて改めました。区分は、(1) 運用ログ、(2) 監査ログ、(3) 業種固有の記録とその変更履歴（自動車編は部品構成の変更履歴）の3つです。監査ログは事業年度末から10年とし、作成日を起点とする日数で設定する場合は 4,018日（11年）としています。
- 本書の要約、図6-1、適用範囲（0.3）、付録E、発注者との合意事項のチェックリスト（13.5）も、この3区分に合わせました。適用範囲には、区分 (3) の記録を扱うシステムを加えています。
- 区分 (3) のうち、契約の終了や型式の生産終了など、事象から期間を数える記録の実装方法（別のバケットへの保存、Object Lock の保持期間の付与と延長、満了後の削除）を 7.3 に追加しました。
- 3区分を説明する 7.1.3 を追加しました。
- 業種固有の節として、0.10（業種編について）、1.10（業種の法令とログ）、2.5.5（LR-05 の業種での適用）、3.5（業種のシステムへの当てはめ）、7.8（業種の保存期間）、12.8（監査・検査対応の留意点）を追加しました。
- 付録G に、根拠とした調査を収録しました。業種編01〜10 は、業種別法令調査のうちその業種に関わる部分（結論、調査の前提、全業種に共通する法令、その業種の章）です。業種編11（自動車）は、自動車業界の調査の全文です。

## 位置づけ

- ガイドラインの対象読者は、AWS 上で財務報告に関連するシステムを開発・運用する開発ベンダーの、設計・構築・運用の担当者です。業種編では、業種の法令や規則に関わる記録（区分 (3)）を扱うシステムも対象に含めています。
- 業種編01〜10 の付録G に収録した業種別法令調査は、日本国内でデータベースを持つ Web システムなどを開発・運用する企業が、監査ログの保存期間を決める場面を対象としています。調査そのものは AWS に限定していません。業種編11 の付録G に収録した自動車業界の調査は、自動車業界の企業（完成車メーカー、部品メーカーなど）が AWS 上で開発・運用する、データベースを持つ Web システムを対象としています。
- ガイドラインは、技術的な要求事項を定めるものです。内部統制の最終的な整備・評価と監査への対応は、発注者（利用企業）の責任で行います。
- 法令調査は、基準日の時点の条文と公開情報に基づきます。重要な判断の前に、最新の条文を確認してください。
